# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.2.0] - 2026-11-10

### Added

- `metero` — live context meter above the prompt showing tokens, cost, model, and rate limits with a color-coded bar
- `namer-cr` — session naming and chat color picker on startup (git-branch-aware)

### Fixed 
- `noti-toasti-windows` notification delivery

## [0.1.0] - 2026-11-08

### Added

- `noti-toasti-mac` — native macOS Notification Center banners with sound for Claude Code events
- `noti-toasti-windows` — native Windows toast notifications with WSL support
- Initial project setup and marketplace configuration
